### Kasia Walter

To create art is to speak another language.
I build interfaces that are meant to be felt, not only used.

**[Resonance Chamber](https://github.com/WhiteLupi/Resonance-Chamber)**: my site, one interactive piece.
WebGL veins grown in shaders, a camera that travels through the page, a frame guard that keeps phones smooth.

**[running-cat](https://github.com/WhiteLupi/running-cat)** 🐈‍⬛: a Claude Code plugin that swaps the spinner for a kitten.
It chases a mouse while Claude answers, types on a tiny laptop while a tool runs, and shows which tool it is, so you can stop a rogue call in time.
